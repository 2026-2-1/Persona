## 팀원 재현

GitHub에서 통합 preview 브랜치를 받아 실행한다. Windows는 Python 경로를 `.venv/Scripts/python.exe`로 바꾼다.

```sh
git fetch origin
git switch --track origin/codex/integration-preview-20261015
.venv/bin/python -m uxagent doctor --study configs/study.json
.venv/bin/python -m pytest -q
.venv/bin/python -m uxagent run --study configs/study.json --provider mock --headless
.venv/bin/python -m uxagent dashboard
```

실행 기록 → AI 생성·비동기 기록에서 인식/계획/행동 제안, 중요도 작업 마지막 상태와 기억 원본을 본다. 계획의 관찰 버튼이 같은 관찰 ID의 이미지를 여는지 확인한다. 자료 내보내기 네 형식도 대조한다. 후보 검토 저장은 [D-05 절차](../tasks/d-review-export-verification.md)의 합성 필터 결함으로 재현한다.

CSV에 Brain 기록이 있으면 `record_type`으로 candidate/brain_stage/brain_task_event/memory/memory_change/brain_warning을 구분한다. 모든 행을 UX 후보로 세지 않는다. 재현자는 OS·커밋·절차·실제 결과를 해당 PR에 남긴다. Python 환경은 [개발 안내](../development.md)를 따른다.
