# D-04 비교표의 측정 범위와 누락 (#35)

D-03 PR #49의 aa3e115 기반 작업이다. 선행 C #30 → D #37 → #38 → #49를 통합한 후 prototype에서 재검증한다. 관련 기존 이슈는 #4/#7/#9/#29이며 #46/#47의 Brain 비교·기록 확장은 별도 범위다.

## 표시 계약

집계는 기존 `aggregate_sessions`를 재사용하며 화면에서 성공률·분모를 다시 계산하지 않는다.

- 성공/예정과 성공률을 표시하고 과업 결과(success/failure/unknown)와 실행 상태(completed/error/cancelled/not_started/running)를 별도 열로 둔다. 예정 0은 성공률 0%가 아닌 예정 세션 없음이다.
- 행동·시간 중앙값은 성공 세션 중 실제 계산 대상 수를 함께 표시한다. 대응쌍 변화량이 아니다.
- 비용·총 토큰·입출력 토큰·요청 수와 제공자별 사용량의 전체값, 측정 부분값, 완전 측정/예정/누락 포함 세션 수를 표시한다. `known_total`에는 불완전 세션의 측정된 일부 호출도 포함될 수 있으므로 완전 측정 횟수와 혼동하지 않는다.
- 기록 확보율의 전체 비율과 측정 범위 complete/attempted 및 known_rate를 분리한다. 기록 대상 행동이 0이면 대상 행동 없음, 값 자체가 누락이면 미확인이다.
- 모델 설정과 실행에 실제 기록된 모델을 구분한다. 과업·반복·URL·viewport·관찰 정책·환경 식별자·사이트/프롬프트 버전 중 누락된 값은 미기록이다.
- scripted/scenario는 C 집계와 대응표에서 제외한다. 개별 실행 파일이 없는 버튼은 비활성이다.
- 상세/이전 비교 펼침은 자동 갱신과 데이터 변경에도 유지한다. 좁은 화면은 표 내부 가로 스크롤을 허용한다.

## 검증과 한계

`tests/test_comparison_browser.py`는 임시 파일 → 실제 집계/HTTP API → Chromium 화면을 사용한다. 2/5 성공, 성공 0, 예정 0, 비용 부분값, 측정된 0, 미측정, 취소·미실행, 중앙값 대상 수, scripted 제외, 링크, 펼침 유지와 390px 화면을 확인한다. 가상 데이터는 실제 AI 성능이나 인간 판단의 증거가 아니다.

실제 검증 수치는 [검증 기록](../verification.md)을 따른다. 비교표 외 단일 실행의 기존 지표 및 조회 실패 표시 정책은 이번 변경에서 다루지 않는다. 회의록/추가 개선 계획 문서 정리는 별도 후속이다.
