# [phase:1] 메모리 검색 점수·가중치 수정 보완

GitHub: [#54](https://github.com/2026-2-1/Persona/issues/54)

## 기준선과 새 정책

- #40 기준선은 중요도 I, 질의 관련성 Q, 최신성 R을 각각 1/3로 합산했다. 산정 전 I가 없으면 Q와 R만 다시 정규화한다. 동점은 최신 생성 순번이 우선이다.
- I는 새 기록 1~10점을 0~1로, 구버전 1.0의 0~5점은 0~1로 정규화한다. Q는 질의 단어 겹침 또는 선택적 embedding의 코사인 유사도를 0~1로 변환한다. R은 생성 이후 경과 시간을 기준으로 60초 반감기 지수 감소를 적용한다. 점수 변경은 다음 검색부터 반영한다.
- Fast 인식은 기준선 I/Q/R을 사용한다. Fast 계획은 원본 UXAgent의 planning 검색처럼 action·plan·reflection을 10배, 다른 종류를 1배로 둔다. Fast 행동 결정은 원본 acting 검색처럼 observation을 0배, action·reflection을 10배, 다른 종류를 1배로 둔다. 현재 관찰과 현재 계획은 검색과 별도로 필수 입력이다.
- Slow 성찰·계획 검토는 I/Q/R을 0.2/0.2/0.6으로 둔다. [UXAgent 원본](https://github.com/neuhai/UXAgent/tree/4d3b1f1c1fef93c5e2ea7d104153ea164ba1acbd)은 성찰에 가장 최근에 추가된 기억을 직접 전달한다. 이 프로젝트는 기록된 검색 출처를 유지하기 위해 최신성 가중 검색으로 그 우선순위를 적용한다. 현재 관찰의 원본 기억은 검색 순위와 별도로 Slow snapshot에 포함한다.
- 종류 가중치의 최대값 10으로 나눠 최종 점수를 0~1로 유지한다. 동점이면 최신 순번을 우선한다. Wonder는 #45의 과업 무관 생각 정책에 따라 원본의 thought 10배 가중치로 올리지 않는다.

## 검증과 제한

- 같은 기억·시각·질의에서 #40 기준선과 Fast/Slow 검색 순서를 비교한다. 미산정·점수 갱신·오래된 고점·최신 저점 사례를 확인한다. Fast의 최근 행동은 별도 `recent_actions`에 남는다.
- 원본은 단계별 timestamp의 `exp(-age)`를 쓰지만 이 프로젝트는 실제 생성 시각을 기록하고 60초 반감기를 사용한다. 시간 척도는 실제 UX 행동 자료로 보정되지 않았다. 미산정 대기 기억의 제거 보호는 #55에서 다룬다.
