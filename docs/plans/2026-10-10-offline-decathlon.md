# API 없는 데카트론 과업 검증 개발 계획

## 범위와 원칙

사용자 승인: 이슈 #2/#3의 세부 조작·검색/필터/상세 평가와 개선 카드 연결, tests/docs/README, prototype 대상 PR·머지. LLM API 키 연결 및 모델 요청은 하지 않는다. 기존 mock/live 경로와 일반/페르소나 비교는 보존한다.

## 구현 순서

1. Enter/Escape/Tab 등 제한된 키 입력, 제한된 페이지 scroll, ARIA checkbox/listbox/option 관찰과 최신 observation 검증을 추가한다. Jev에 종료 후보를 제공하고 행동과 종료 선택을 구분한다.
2. 검색/빈 결과/조건 필터/해제/상세 필수 정보의 독립 DOM 평가를 추가한다. 합성 스포츠 상품·custom filter·지연/의도적 결함을 가진 재현 페이지와 선택자 프로필을 제공한다. live 사이트 자료와 혼동하지 않는다.
3. 사전 정의한 단계와 기대 결과를 실행하는 API 없는 시나리오 실행기를 추가한다. 각 단계의 전후 observation/시간/결과/평가를 기존 로그 계약으로 저장한다. 사이트 origin과 허용 조작 경계를 유지한다.
4. CLI/대시보드에 API 없는 과업 검증 진입점을 제공한다. 시나리오를 선택해 실행·근거·실패 카드를 확인한다. 실패 카드에 실제 실패 단계, 관찰 사실, 가설, 수정·재검증 조건을 연결한다.
5. 정상/빈 결과/필터 불일치/해제/정보 누락/키·scroll/오래된 ID/외부 origin/기록 누락을 검증한다. 모든 API provider 메서드를 실패시키는 테스트로 API 무호출을 보장한다.
6. 독립 코드 리뷰와 로컬/Windows/Linux 검사를 확인하고 PR을 prototype에 머지한다. 이슈 완료 범위와 live 검증 제한을 기록한다.

## 완료 판단

대표 검색·필터·상세 시나리오가 코드 평가와 근거를 남기고 실패 카드/출력으로 이어진다. 기존 mock 6단계와 UI·키 보호 회귀가 유지된다. 라이브 Decathlon 선택자는 실제 브라우저 확인된 것만 검증 완료로 표시하며, 접근 제한은 우회하지 않는다. AI 판단 성능/페르소나 효과는 API 미연결이라 미검증이다.
