## 실험과 연구

현재 기준선은 U Fast와 단일 Slow의 reflect → wonder → memory.update다. 예전 plan_review·채택 게이트·1% Wonder 정책은 새 실행에서 제거됐으므로 과거 off/빈도 실험안을 그대로 적용하지 않는다. 연구용 조건 제어는 기준선과 분리한 후속 구현이며 회의에서 변수·비용 상한·평가 기준을 확정한다.

| 단계 | 진행 내용 | 완료 근거 |
| --- | --- | --- |
| 기준선 파일럿 | 같은 모델·과업·환경의 실행과 실패 원인 기록 | 재현 로그, 독립 판정, 실제 사용량 |
| 평가셋·사람 검토 | 공개/합성 자료와 기업 제공 자료를 구분하고 2인 판정 | 데이터 정의·수량·사용 범위, 판정 지침·합의 |
| 통제 실험 | Slow/검색/프롬프트 등 한 변수씩 비교 | 고정 조건·반복 수·성공률·오탐·비용·지연 |
| 실무 비교 | 프로토타입 시연 후 멘토에게 제공 가능한 자료 확인 | 자료 수령과 권한, 실무 기준과의 차이 |
| 추가 방향 | MiroFish 보조 persona·공개 데이터 활용·파인튜닝 검토 | 별도 평가셋에서 개선 확인 후 채택 |

기업체 데이터는 현재 사용자 확인 기준 미수령 0건이다. 모델 생성 설문은 AI 자기보고이며 사람의 행동·판단을 대체하는 정답으로 사용하지 않는다. 작은 파일럿 결과를 연구 효과나 Novelty의 검증으로 확대하지 않는다. [연구 실험안](research/2026-10-15-slow-loop-experiment-plan.md), [기업 데이터·시스템·Novelty 제출 초안](research/2026-10-15-project-submission-draft.md).

## 범위와 후속 기능

로컬 Python/Playwright 실행기를 유지한다. 현재 제품은 설정 → 실행/비교 → 근거 → 사람 검토 후보 → 출력 흐름이다. UI/로그/리포트에서는 AI 생성물·관찰 사실·독립 평가·사람 검토를 구분한다.

- 공개 데카트론은 지정 검색 결과와 상세 이름/가격의 부분 범위다. 검색 제출·필터 초기화·색상/사이즈/재고/픽업·전체 네 과업 확대는 [#19](https://github.com/2026-2-1/Persona/issues/19)다.
- 4개 과업·모바일/느린 네트워크·2인 검토·개선 전후 비교는 [#10](https://github.com/2026-2-1/Persona/issues/10)이다.
- 기법별 비교와 연구용 조건 제어는 [#11](https://github.com/2026-2-1/Persona/issues/11), 논문·재현 자료는 [#12](https://github.com/2026-2-1/Persona/issues/12)다.
- ChatGPT 구독 연결·자유 Q&A·공개 호스팅/다중 사용자 키 관리·전체 큐/DB는 별도 후속이다.
