# 현재 구현 상태

기준: prototype 원본 e4dfa98 이후 작업, 2026-10-15 #47 두 루프 기록 소비 연결 구현. 실제 검사 결과는 verification.md를 따른다.

## 구현됨

- Python 3.11+ / Playwright Chromium / Pydantic.
- 화면 내 DOM 관찰, 최신 관찰에 묶인 요소 ID, 클릭·입력·hover·select·탐색·탭 조작.
- Mock, OpenAI Chat Completions, Claude Messages (Sonnet 4.6), Gemini, Jev 후보 선택과 Gemini fallback.
- 요청·토큰 예산, 반복/시간/단계 제한, 허용 origin 검사.
- 메모리 검색, 선택적인 embedding, 실행별 Brain의 필수 Fast/Slow Loop와 기본 활성 Wonder.
- #45에서 실제 시작된 reflection/plan_review마다 1%를 추첨한다. 당첨 시 과업·화면·기억·`intent` 없이 persona만으로 별도 비동기 요청을 보내 가정된 생각을 생성한다. 일반 AI 조건에는 공통 제약만 보낸다. 추첨과 작업 상태를 남기고 생성 생각을 실제 사용자 기억과 구분해 표시한다.
- #46에서 Fast/Slow/Wonder/embedding의 호출별 실제 provider·model과 실패·재시도·취소를 기록한다. 실행 요약에는 모델 경로, 공통 예산과 요청/토큰 한도 사유를 남긴다. Jev의 후보 선택은 Jev, 생성은 선택한 Gemini 모델로 나뉜다. Jev/Gemini 키나 미지원 embedding 조합은 실행 전 거부한다. 일반 조건은 모든 생성 단계에서 persona 배경·선호를 제외한다.
- #47에서 실행 상세는 단계·작업 사건·원본 기억과 활성 제거 기록을 행동 관찰 ID로 연결한다. 대시보드와 JSON/CSV/Markdown/HTML 출력에서 AI 생성물, 실행된 행동, 독립 평가를 구분한다. 새 로그가 없는 이전 실행과 null 행동 기록은 빈 근거로 읽는다.
- #44에서 관찰 근거 저장 → Brain 판단 → ActionExecutor 실행 → 재관찰 → 독립 평가 순서를 연결했다. 종료 선언도 현재 화면을 독립 평가한다. 대시보드의 일괄·비교 중지는 현재 행동의 결과와 재관찰 기록을 완료한 뒤 종료한다.
- #39에서 생성 결과·비동기 작업·메모리 점수/제거 사건의 스키마를 정의했다. `MemoryEntry`의 새 기록은 버전 2.0이며 중요도는 산정 전 `null`, 산정 후 1~10점이다. 구버전 1.0의 0~5점 로그는 구분해 읽는다. #41에서 perception·plan·decision, #42에서 reflection·plan_review 결과, #43에서 Brain 단계 경계 채택·stale 폐기·실행 취소 상태를 기록한다.
- #40에서 Fast 모델 입력의 검색 점수 상위 기억(후보 선택 모델 4개, 생성 모델 6개)과 최근 행동 이력을 분리했다. 활성 기억은 기본 64개(설정 10~64개)로 제한하며 최근 10개 과업 기억을 보호한다. Wonder는 먼저 제거한다. Slow가 persona·intent·현재 계획·기억을 사용해 미산정 기억을 1~10점으로 비동기 산정하고, 원본 ID를 유지한 채 변경 사건을 남긴다. 실패·예산 소진·종료 취소는 작업 사건으로 기록한다. I/Q/R 검색 가중치는 #54 전까지 동일하다. #43의 Slow 대기열은 상한을 두지 않는다.
- 로컬 템플릿 persona 생성, 순차 격리 batch, 로그/PNG, 로컬 대시보드.
- 로컬 가방 fixture의 독립 성공 판정, 규칙 기반 문제 후보·HTML review·기록 조합 설문/인터뷰.

## 1차 MVP 추가 구현

- strict 외부 DOM/URL 확인 조건, fixture 검색·필터·상세의 최종 상태 근거.
- 일반/페르소나 프롬프트 분리, 대응 비교 세션 사전 등록·고정 분모·중지·순서 seed.
- 전후 화면/URL/시각/결과 기록 확보율, 도구 실행 수준의 오류 복구 보조 지표.
- 디자인 기준의 테스트·비교·개선·기록 화면, API 키 연결 확인, 실행 중지.
- 미검토 문제 카드와 JSON/CSV/Markdown/HTML 내보내기.
- 옵션 후보 ID 충돌, null 결과 보고서 처리, 실제 검색어 생성/교체 경로 수정.

## 미구현 또는 미검증

- #44의 협력적 중지는 현재 행동 timeout까지 기다릴 수 있다. OS 강제 종료·프로세스 충돌의 원자적 기록은 보장하지 않는다.
- Slow 결과로 후속 계획을 자동 재작성하는 정책과 활성 메모리 N개 상한의 별도 재검토는 후속 구현이다. #43의 plan review는 동일한 observation·plan 버전의 decision 직전에만 채택되며 다음 계획을 덮어쓰지 않는다. 설정 파일의 구버전 `enable_slow_loop=false` 값은 호환을 위해 받아들이지만 실제 AI 실행은 두 루프를 사용한다. Wonder의 과업 무관성·인간 행동 확률은 검증되지 않았다.
- 실제 대상 전체 4개 과업·환경의 독립 평가와 색상/사이즈/재고/픽업. 합성 네 시나리오와 공개 데카트론의 제한된 결과·가격·상세 점검은 아래 범위로 구분한다.
- 근거 Q&A, ChatGPT 구독 OAuth/Responses 연동. 현재 설정은 목표 → 사용자 → 모델 → 실행의 안내형 4단계이며 생성과 실행은 자동으로 이어진다.
- 2인 사람 판정·합의와 개선 전후 자동 재검증. 현재 카드는 미검토 후보다.
- 환경별 비교, 복구 사건 분석, 전체 서비스 큐/DB/스토리지.
- 실제 LLM API·사람 행동 재현은 이번 API 없는 작업의 검증 범위가 아님. 공개 데카트론은 부분 범위만 실제 실행했다.

## API 없는 과업 점검

- 사전 정의 scripted 실행기·대시보드·CLI, 합성 검색/필터/상세·빈 결과·초기화·스크롤 네 preset와 결함 주입.
- 단계별 독립 DOM 판정·근거 연결·실패 카드·오류 후보. API 연결과 페르소나 생성 없이 실행한다.
- 실제 공개 데카트론 지정 검색 URL의 결과 이름, 가격 상한과 표시 카드 가격, 상세 상품명·가격을 Python 실행기로 확인했다. 검색 폼 제출은 별도 실행에서 unknown, 색상/재고/픽업 등은 미검증이다.
- 자세한 사용법과 범위는 [API 없는 과업 점검](offline-scenarios.md), 실제 결과는 [검증 기록](verification.md)을 따른다.

## 수정 전 확인할 제한

- 관찰은 viewport DOM이다. keypress는 안전 키 여섯 개, scroll은 명시적으로 활성화한 ±900px 범위를 지원한다. iframe/canvas/복잡한 shadow DOM/password는 미지원. custom combobox는 관찰된 클릭·키·option만 가능하며 native select로 처리하지 않는다.
- Jev는 실제 입력값을 Gemini로 생성한다. 옵션 ID 충돌은 회귀 수정됐고 완료/진행 불가 종료 후보를 지원한다. 모델 완료 선언은 독립 성공 판정과 구분한다.
- 외부 사이트는 명시적 확인 조건이 없으면 unknown이다. 모델 완료 선언을 성공으로 볼 수 없다.
- 설문·인터뷰는 현재 자유로운 대화 모델이 아닌 기록 기반 템플릿이다.
- 평가 오류는 failure/unknown/종료 사유를 함께 읽어야 한다. 과업 실패와 시스템 기능 실패를 분리한다.

2026-10-11 화면 정리: 메뉴와 중복되는 제목/설명을 숨기고 desktop 설정/최근 기록·실행 근거/판정을 좌우로 배치했다. 추가 자료·기록 검색은 펼쳐 확인하고 모바일은 한 열이다. 실제 재검증 결과는 verification.md 참조.

점검 판정은 아이콘/항목/상태를 한 행으로 정리하고 근거 펼침을 자동 갱신에서도 유지한다. 판정 데이터는 변경하지 않는다.


## 모델 선택과 설정 도우미

3단계에서 제공자와 모델을 선택하고 **키 발급 페이지 → 키 입력 → 연결 확인**으로 진행합니다. 모델을 바꾸면 다시 연결을 확인합니다. 오른쪽 도우미의 쇼핑 검색·정보 찾기·예약 안내·입력 오류는 시작용 예시이며 사용 빈도 순위가 아닙니다.

연결 전에는 무료 예시와 공식 발급 안내를 제공합니다. 연결 확인 후 **추천받기** 또는 질문 전송을 누르면 선택한 모델을 호출합니다. 추천 사용자·목표는 적용 버튼을 눌러야 설정에 반영됩니다. 추천은 가정이며 실제 사용자 조사 결과가 아닙니다. 최종 사용자 프로필 생성은 기존 로컬 템플릿을 유지합니다.

도우미는 서버 실행당 최대 5회, 보수적 토큰 예산 12,000, 출력 최대 1,000/회입니다. 실패 요청도 한도를 소비합니다. 사용량과 비용은 응답에 나온 값이며 계정 잔액과 다릅니다. 가격을 확인할 수 없는 모델은 비용 미확인으로 표시합니다. 대화는 메모리에만 유지하며 키·인증 URL은 질문에 입력하지 않습니다.

지원 모델 목록은 현재 구현과 호환되는 선택지이며 최신·전체 모델 목록을 보장하지 않습니다. Gemini 2.5 접근이 제한된 계정은 3.5 Flash Lite를 확인하세요. Jev 키 메뉴의 상세 경로는 확인되지 않아 콘솔 안내를 따릅니다. 실제 유료 API 연결은 개발 검증에 포함하지 않았습니다.
