# 초보자용 설정·테스트·비교 대시보드

## 현재 상태 (2026-10-11)

1차 화면은 디자인 기준으로 구현했다. 설정은 4단계 다음/이전 흐름과 자동 생성·실행으로 개선했다. 기록 검색·결과 필터와 근거 버튼을 추가했다. 메뉴와 중복되는 본문 제목을 숨기고 desktop에서 설정/최근 기록·근거/판정을 좌우 배치했다. 추가 자료와 긴 기록 검색은 펼쳐 확인하며 모바일은 한 열이다. 기능 판정은 정렬된 아이콘·항목·상태 행으로 표시하며 클릭해서 근거를 확인한다. 실제 부분 재실행과 화면 검사 근거는 docs/verification.md와 docs/plans/2026-10-11-compact-dashboard.md를 따른다. 자유로운 모델 대화 설정/근거 Q&A는 후속 기능이다.

아래 체크리스트는 전체 목표이며 현재 상태 문단과 구분한다. 구현·검증된 항목은 후속 작업에서 중복 구현하지 않는다.
