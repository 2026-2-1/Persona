# 한눈에 보는 대시보드

사용자 요청: 실제 데카트론 부분 점검 결과와 카드를 확인하고, 중복 화면 제목을 제거하며 주요 요소를 좌우 배치한다.

- 상단 메뉴가 화면 이름을 대신한다. 기존 제목 ID는 접근/소비 호환을 위해 숨긴다.
- desktop 1365×768 및 1280×720에서 설정/최근 기록은 좌우, 결과 근거/판정은 좌우로 놓는다. 실행 선택은 항상 보이고 긴 목록·프로필·호출·내보내기는 펼쳐 확인한다.
- 주요 화면과 타임라인은 제한 높이를 쓰며 작은 화면은 한 열과 자연스러운 스크롤을 유지한다. 근거를 잘라 판정 의미를 바꾸지 않는다.
- 실패 재현 레이아웃 테스트 → 최소 HTML/CSS 변경 → 기존 위저드/키/기록/모바일 회귀 → 실제 공개 부분 실행·개선 카드 확인 → 문서 기록.

모델 API를 호출하지 않고 독립 판정과 미검증 범위를 유지한다. 실제 부분 점검 통과 시 문제 카드를 임의 생성하지 않는다.
