# 실행 기록 검색·필터와 읽기 쉬운 개선 근거

관련 상위 이슈: #7

## 범위

전체 기록을 검색·상태 필터로 조회하고 12건 제한으로 숨겨진 기록을 접근할 수 있게 한다. 개선 카드는 원시 JSON 대신 분류/요약/근거 버튼을 표시한다. 기존 #7/#8의 전체 기능은 계속 열린다.

## 완료 조건

- 구현과 실제 회귀 검사를 기록한다.
- 사용자 입력/선택 유지, 오류/미확인 상태를 보존한다.
- README와 관련 docs를 갱신한다.
- prototype 대상 PR로 리뷰·CI 후 머지한다.

## 구현 결과

사용자·제공자·모델·실행 ID 검색, 결과 필터, 14건 접근, polling 중 검색/선택 유지, 개선 카드 분류/쉬운 요약/근거 버튼/접힌 원자료를 구현했다.
