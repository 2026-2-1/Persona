## 범위

목표 → 사용자 → 모델 연결 → 확인의 4단계로 구성한다. 이전/다음으로 이동하며 마지막 실행 버튼은 persona 생성 후 선택한 과업/비교를 자동 시작한다. 입력 검증, 생성 실패/중지, 키 연결 상태, 재실행을 다룬다. 기존 #7의 자유 대화 Q&A는 이번 범위 밖이다.

## 완료 조건

- 구현과 실제 회귀 검사를 기록한다.
- 사용자 입력/선택 유지, 오류/미확인 상태를 보존한다.
- README와 관련 docs를 갱신한다.
- prototype 대상 PR로 리뷰·CI 후 머지한다.
