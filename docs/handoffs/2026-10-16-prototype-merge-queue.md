# 2026-10-16 prototype squash 병합 절차와 검증

## 적용 범위와 승인

통합 대상은 `prototype`이며 `main`은 변경하지 않는다. 사용자가 이번 작업에 한해 필수 승인 수를 1→0으로 잠시 변경하는 것을 명시적으로 허용했다. **각 병합 시도 직후 성공·실패와 관계없이 승인 수를 1로 복원한다.** Ubuntu/Python 3.11, Windows/Python 3.13 필수 CI, 최신 base 요구, 관리자 적용과 기타 보호 조건은 유지한다.

원격 완료 상태는 각 PR의 merged 상태와 squash commit으로 확인한다. 이 문서의 순서는 병합 절차이며, 준비본의 로컬 통과를 원격 병합이나 CI 성공으로 간주하지 않는다.
